# Phase 7 Implementation Plan — Polish + Production Readiness

**Goal:** Make Ghost Chat ready for TestFlight and Google Play Internal Testing. Finish ML-KEM
hybrid handshake, wire auto-rotation, add timestamp-based replay, initialize Sentry, polish UI,
clean Material3 deprecations, real incoming-call surface on Android, App Store / Play metadata,
localization completeness. End with `verify_phase_7.sh` exit 0.

**Architecture:** Extend Phase 6 primitives without introducing new abstractions. Wire already
existing `PostQuantum`, `ContactKeyRotation`, `ReplayGuard` modules into the live code paths.
Keep iOS ↔ Android wire + state byte-identical. No backwards compatibility — this is a
pre-TestFlight cut, nothing in the wild to break.

**Tech stack:** Swift 5.9 / iOS 16+, Kotlin 2.1 / AGP 8.7.3 / minSdk 28, CryptoKit,
BouncyCastle 1.82, Sentry (cocoa + android), SQLCipher, WebRTC (stasel / stream).

**Protocol (plaintext over DC before encryption is live):**
```
HOST.beginHandshake() → KeyExchangePacket{
    publicKey,          // ECDH ephemeral pub (x963, 65 bytes)
    identityKey,
    pqKey = MLKEM_pub,  // only if PostQuantum.isSupported on HOST role
    pqSupported = true/false
}
GUEST.beginHandshake() → KeyExchangePacket{ publicKey, identityKey, pqSupported }

Simultaneous send on DC-open:
  HOST → GUEST: KeyExchangePacket
  GUEST → HOST: KeyExchangePacket

GUEST receives HOST's packet:
  - ECDH(guestEph.priv, hostEph.pub) → ecdhSS
  - if HOST.pqKey != nil AND GUEST.isSupported:
      encap = MLKEM.encapsulate(HOST.pqKey) → (ciphertext, pqSS)
      hybridSS = hybridDeriveSharedKey(ecdhSS, pqSS)
      send PqExchangePacket{ pqCiphertext: ciphertext } over DC
  - else:
      hybridSS = hybridDeriveSharedKey(ecdhSS, nil)
  - init DoubleRatchet(role=guest, sharedKey=hybridSS, ourKp=guestEph, theirPub=nil)
  - state = .ready

HOST receives GUEST's packet:
  - ECDH(hostEph.priv, guestEph.pub) → ecdhSS
  - if HOST.pqKey was sent (we advertised PQ):
      state = .awaitingPq(ecdhSS, mlkemPriv, peerIdentity, guestEph.pub)
  - else:
      hybridSS = hybridDeriveSharedKey(ecdhSS, nil)
      init DoubleRatchet(role=host, sharedKey=hybridSS, ourKp=hostEph, theirPub=guestEph)
      state = .ready

HOST receives PqExchangePacket:
  - pqSS = MLKEM.decapsulate(pkt.pqCiphertext, mlkemPriv)
  - hybridSS = hybridDeriveSharedKey(ecdhSS, pqSS)
  - init DoubleRatchet(role=host, sharedKey=hybridSS, ourKp=hostEph, theirPub=guestEph.pub)
  - state = .ready
```

    override fun onIncomingCall(roomId: String, callerName: String) {
        val id = UUID.randomUUID()

        // Register PhoneAccount on first call, then use TelecomManager.addNewIncomingCall.

        val extras = Bundle().apply {
            putString("roomId", roomId)
            putString("callerName", callerName)
            putParcelable(
                TelecomManager.EXTRA_INCOMING_CALL_ADDRESS,
                Uri.fromParts("ghostchat", roomId, null)
            )
        }
        tm.addNewIncomingCall(account, extras)
    }
    override fun onInvite(roomId: String, callerName: String) { /* show notif */ }
    override fun onNotify(type: String, senderName: String) { /* show notif */ }
