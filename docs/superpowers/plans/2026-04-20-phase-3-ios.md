# Phase 3 — iOS App Implementation Plan

> **Goal:** Production-grade iOS client of Ghost Chat that creates/joins rooms, runs P2P encrypted messaging over DataChannel, makes voice calls via WebRTC+CallKit, persists saved contacts in SQLCipher, locks with biometrics, survives `verify_phase_3.sh` with exit 0.

**Architecture:** Feature-modular SwiftUI app. `Core/` = stateless services and stateful managers; `Features/` = self-contained screens (View + VM); Models are plain structs. App entry orchestrates CallKit + PushKit + deep links. Crypto comes from the existing `GhostCrypto` Swift package (Phase 2, frozen).

**Tech stack:**
- Xcode 26.2 / Swift 6.2 / iOS 16.0+ / SwiftUI
- XcodeGen → `.xcodeproj`
- SPM: `stasel/WebRTC`, SQLCipher-backed GRDB, Sentry, local `GhostCrypto`
- Testing: XCTest for Core + Managers; manual for UI/WebRTC

---

## GUIDING CONSTRAINTS (from SPEC + CLAUDE.md)

- Every file **< 400 LOC**; ChatViewModel **≤ 300 LOC** (thin orchestrator).
- **No force unwraps** outside IBOutlets (we don't have any).
- **No UserDefaults** — Keychain + SQLCipher only.
- **No logging of decrypted content or key material.**
- Certificate pinning: **no fallback** — failed pin = connection dies.
- Crypto ops off main thread.
- Test-first for crypto.
- Commits after every passing stage.

## DEPENDENCY DECISIONS (locked for review)

| # | Decision | Choice | Rationale |
|---|----------|--------|-----------|
| 1 | WebRTC SDK | `stasel/WebRTC` v123+ via SPM | actively maintained; Google dropped publishing; same one both Ghost v1 iOS and stream-webrtc-android speak to |
| 2 | SQLCipher | GRDB via `groue/GRDB.swift` with SQLCipher build product | type-safe query API, proven SQLCipher integration, far fewer raw-string bugs than SQLite.swift |
| 3 | Sentry | `getsentry/sentry-cocoa` SPM | already decided for Android; crash reporting required by CLAUDE.md |
| 4 | Crypto | local GhostCrypto package (Phase 2) | **no changes** — imported as SPM product |
| 5 | Post-Quantum | deferred to Phase 6 per CLAUDE.md | iOS 26+ API gate kept but feature-flagged off |
| 6 | SwiftLint | skip automated install; rely on Swift compiler warnings | keeps verify_phase_3.sh portable; install later if desired |
| 7 | UI Testing | manual (in simulator) for Phase 3 | XCUITest adds 2–3 hours per screen; defer until Phase 7 polish |

### Stage 5 — Core/Crypto (wrapper layer)

**Files:**
- `Core/Crypto/IdentityKeyService.swift` (~120 LOC)
- `Core/Crypto/GhostCrypto.swift` (~260 LOC) — wrapper around `DoubleRatchet`
- `GhostChatTests/Crypto/GhostCryptoTests.swift`

**IdentityKeyService:**
```swift
final class IdentityKeyService {
    func getOrCreateIdentity() throws -> P256.KeyAgreement.PrivateKey
    var publicKeyData: Data { get throws }     // 65-byte x963
    var publicKeyRaw64: Data { get throws }    // without 04 prefix
    func resetIdentity() throws                // panic wipe path
}
```
- Private key stored in Keychain under `identity.private.key`
- Generated on first call
- Public key cached in memory

**GhostCrypto wrapper:**
```swift
final class GhostCrypto {
    init(identity: IdentityKeyService)
    func startKeyExchangeAsHost() throws -> KeyExchangePacket
    func startKeyExchangeAsGuest() throws -> KeyExchangePacket
    func completeKeyExchangeAsHost(peer: KeyExchangePacket) throws
    func completeKeyExchangeAsGuest(peer: KeyExchangePacket) throws
    func encrypt(_ plaintext: String) async throws -> String // base64
    func decrypt(_ wire: String) async throws -> String
    func currentFingerprint(peerIdentity: Data) throws -> String
    func serializeState() throws -> Data                     // for saved contacts
    init(state: Data, identity: IdentityKeyService) throws
}
```
- `KeyExchangePacket` Codable: `{type: "key-exchange", publicKey, identityKey, v: 3}`
- Timestamp validation: reject ±5 min
- Replay: in-memory nonce set, max 1024 entries LRU (one-time rooms)
- Runs all ops on `DispatchQueue.global(qos: .userInitiated)` / async

**Tests:**
- Host↔Guest key exchange → both derive same root key (use fixed seeds)
- Encrypt → Decrypt roundtrip
- Replay detection returns `RatchetError.replayDetected`
- State serialize → deserialize → resume encryption

### Stage 6 — Core/Network

**Files:**
- `Core/Network/CertificatePinning.swift` (~140 LOC)
- `Core/Network/SignalingClient.swift` (~320 LOC)
- `Core/Network/TURNService.swift` (~100 LOC)
- `GhostChatTests/Network/CertificatePinningTests.swift`

**CertificatePinning:**
- Implements `URLSessionDelegate.urlSession(_:didReceive:completionHandler:)`
- Compute SPKI-SHA256 of server leaf certificate
- Compare against two baked-in pins (current + backup)
- Any mismatch → `completionHandler(.cancelAuthenticationChallenge, nil)`
- Pins as array of base64 strings in a Swift constant (documented how to rotate)

**SignalingClient:**
- `URLSession.shared.webSocketTask(with: URL(string: "wss://ghostchat.one/ws"))`
- Pinned via custom `URLSession(configuration: ..., delegate: pinning, delegateQueue: .main)`
- Publishes incoming `SignalingEvent` enum via `AsyncStream`
- Outgoing API: `createRoom()`, `joinRoom(id:)`, `rejoin(id:role:)`, `signal(data:)`, `leaveRoom()`
- Reconnect with exponential backoff (250ms → max 10s) when `room-joined` has been seen
- Ping timer every 30s (WS Ping frame)

**TURNService:**
- `GET https://ghostchat.one/api/turn-credentials` via pinned session
- Returns `(username, credential, urls, ttl)`
- Re-fetch when < 5 min left

**Tests:**
- CertificatePinning: supply test cert, verify SHA256 matches — minimal unit test with bundled fixture

### Stage 7 — Core/WebRTC

**Files:**
- `Core/WebRTC/GhostRTC.swift` (~380 LOC) — close to limit, split if grows
- `Core/WebRTC/GhostVoice.swift` (~200 LOC)

**GhostRTC:**
- Build `RTCPeerConnection` via `RTCPeerConnectionFactory` (initialized once at app start)
- `RTCDataChannel(label: "ghost-chat", ordered: true, reliable: true)`
- STUN: `stun.l.google.com:19302`, `stun.cloudflare.com:3478`
- TURN: urls from TURNService
- `iceTransportPolicy = .relay` when privacyMode enabled
- Filter ICE candidates in `peerConnection(_:didGenerate:)`:
  - drop host (local IP) candidates
  - drop IPv6 link-local
  - forward rest to signaling
- Perfect negotiation roles: guest=polite, host=impolite
- DataChannel label validator: if `!= "ghost-chat"` → close connection
- Disconnect grace: 5 seconds after `iceConnectionState == .disconnected` before declaring `.failed`

**GhostVoice:**
- `AVAudioSession` category `.playAndRecord`, mode `.voiceChat`
- Audio track added via `RTCPeerConnectionFactory.audioTrack`
- `sender.track = nil` for mute (don't `removeTrack` — preserves transceiver) — per existing lessons-learned memory
- Echo cancellation + noise suppression via default audio constraints
- Route switching (earpiece ↔ speaker) via `AVAudioSession.overrideOutputAudioPort`
- Configure session ONLY inside CallKit's `CXProviderDelegate.didActivate`

**Manual test strategy:** two simulators on LAN + loopback. Full E2E tested in Phase 3 final verification.
